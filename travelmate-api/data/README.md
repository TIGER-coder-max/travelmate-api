# Listing research drafts

`listing-drafts.json` contains public-information research only. These records are not database seeds and must not be imported or activated until the named operator gives written permission.

Before activation:

1. Confirm the business identity and authorized contact.
2. Obtain permission to display its name, description and approved photographs.
3. Confirm current price, currency, availability and cancellation terms.
4. Agree on booking, payment and commission arrangements.
5. Create or connect the correct vendor account.
6. Review every field with the operator before setting `is_active` to true.

`null` values are intentional. They identify facts that were not published or could not be safely verified.
